About this project

Edit this paragraph to explain the concept in your own words: this site takes specific things Trump has done that would be considered scandalous, unpopular, or disqualifying if any other president — including a Democrat like Biden — had done them, and reframes each one as a hypothetical headline.

The point isn't that Biden did any of this. It's to test whether the reaction to a given action depends on who did it, or on what the action actually was.
